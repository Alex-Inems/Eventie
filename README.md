# Eventie

Eventie is a Next.js-powered event management platform that allows organizers to create, manage, and sell tickets seamlessly. It features secure authentication, dynamic ticketing, real-time attendee tracking. Built with Next.js, Firebase, Paystack,  and Tailwind CSS, Eventie ensures a smooth and scalable event-hosting experience
